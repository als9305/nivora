# DeepGuard Datasets & Evaluation Fixtures

This directory documents sample testing datasets and attack simulation fixtures for hackathon benchmarking.

## Evaluation Fixtures

1. **Genuine Video / Audio Clips**:
   - `genuine_face_sample.mp4`: Recorded 5-second camera clip with active liveness movement.
   - `genuine_voice_sample.wav`: Clean speech utterance of challenge phrase.

2. **Photo Replay Attack Clips**:
   - `photo_attack_sample.mp4`: Static printed photo held in front of webcam sensor.

3. **Deepfake Face Swap Clips**:
   - `deepfake_face_swap.mp4`: AI-generated synthetic face swap video.

4. **Voice Clone / TTS Samples**:
   - `voice_clone_tts.wav`: ElevenLabs synthetic voice clone utterance.
